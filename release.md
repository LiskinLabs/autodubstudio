# AutoDub Studio v0.0.1 Beta - Обновление

В этом обновлении мы значительно переработали архитектуру интерфейса и добавили поддержку новых движков.

## Основные изменения в релизе 0.0.1:
1. **Объединенный интерфейс загрузки (Unified UI)**
   - Теперь локальные файлы и ссылки (YouTube, X, TikTok) загружаются через одно удобное окно (Drag & Drop + URL Input).
   - Интегрирован парсер YouTube с возможностью выбора оригинальных субтитров и нужной аудиодорожки.
2. **Динамический выбор ИИ Моделей**
   - Выбор моделей (перевод, TTS) теперь скрывает ненужные настройки и показывает кнопки с шестеренкой для ввода API-ключей только когда они действительно нужны (DeepSeek, OpenAI, Edge-TTS).
3. **Глобальная поддержка языков**
   - Перевод субтитров теперь доступен на все языки, которые поддерживает Google Translate (более 100).
   - Озвучка (TTS) автоматически ограничивается только теми языками, которые поддерживаются выбранным движком.
4. **Интеграция WhisperX**
   - Внедрена поддержка WhisperX для точного тайминга (word-level alignment). Теперь можно выбрать движок транскрибации (Standard Faster-Whisper или WhisperX) в расширенных настройках.
5. **Фикс Cookie YouTube**
   - Исправлена критическая ошибка валидации файлов cookies (Netscape format) для обхода ограничений YouTube при скачивании (yt-dlp).

Приложение по-прежнему полностью локально и бесплатно для использования!
