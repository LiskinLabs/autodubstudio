# 🚀 Стратегический план улучшений AutoDub Studio (Netflix-Level Pipeline)

Этот документ содержит архитектурный план и промпты для постепенного внедрения передовых функций (анализ VideoLingo). Мы будем внедрять их шаг за шагом, тестируя каждую функцию локально перед пушем в репозиторий.

---

### 1. Этап 1: Интеграция NLP-сплиттера (Spacy) [✅ DONE]
**Цель:** Разделять транскрибированный текст от Whisper не по паузам в аудио, а по логическим границам предложений (точки, запятые). Это избавляет от «рваных» фраз в субтитрах и улучшает контекст для LLM-перевода.

*   **Библиотека:** `spacy` (для мультиязычности: `en_core_web_sm`, `ru_core_news_sm`).
*   **Логика:**
    1.  Получаем список сегментов от Whisper (`text`, `start`, `end`).
    2.  Объединяем текст, прогоняем через `spacy` (`doc.sents`).
    3.  Пересчитываем `start` и `end` пропорционально длине новых предложений.
*   **Статус:** **Реализовано**. Скрипт `nlp_splitter.py` добавлен, интегрирован в `engine.py`, добавлен тумблер в интерфейс.

## 📚 Этап 2: Управление Глоссариями (Custom Terms)
**Цель:** Запоминание и форсированное использование нужной терминологии.

- **Backend:**
  - Создание эндпоинтов для сохранения/редактирования/загрузки JSON глоссариев.
  - ИИ-помощник для глоссариев: Автоматически сканирует транскрипт и генерирует черновик глоссария (ключевые термины).
- **Frontend:**
  - Вкладка `Настройки -> Глоссарии` для ручного редактирования.
  - Блок на главном экране "Выбор глоссария" с галочками для текущего видео.

---

## 🎬 Этап 3: Трехэтапный "Netflix" Перевод
**Цель:** Естественный перевод без потери тайминга.

**Логика работы:**
1. **База (Google / DeepL):** Быстрый, дешевый буквальный перевод.
2. **Саммари (ИИ):** Анализ всего текста и создание короткого контекста видео + интеграция глоссария.
3. **Netflix Адаптация (ИИ):** ИИ читает буквальный перевод, саммари и глоссарий, после чего переписывает фразы так, чтобы они звучали культурно корректно и гладко для носителя языка, сохраняя количество слов для тайминга.

- **Frontend:** Переключатель "Netflix Pipeline (3 шага)" в настройках перевода.
