# AutoDubStudio — Проектные Установки

## 🎯 Философия Проекта
1.  **Качество > Скорость:** Мы всегда выбираем более глубокий анализ (Reflection в переводе, Demucs для голоса), даже если это замедляет процесс. Результат должен звучать профессионально.
2.  **Стабильность:** Изоляция тяжелых моделей через подпроцессы. Приложение не должно падать при нехватке VRAM (авто-переключение на CPU).
3.  **Локальность:** Максимальное использование локальных мощностей (Faster-Whisper, Qwen, F5-TTS) при сохранении возможности подключения облачных API для слабых ПК.

## 📦 Стратегия Дистрибуции
1.  **Этап 1: Portable-дистрибуция.** Сборка папки со всеми зависимостями (`uv`, виртуальные окружения, веса моделей). Пользователь просто запускает батник или `.exe` дирижер.
2.  **Этап 2: Финальный .exe.** Упаковка через Nuitka/PyInstaller с вшитыми библиотеками CUDA и интеллектуальным загрузчиком весов.

## 🏗️ Архитектура (V3)
- `engine.py`: Пайплайн дубляжа (высокоуровневая логика).
- `backend/`:
    - `translator.py`: Объекты-переводчики (Google, LLM, Qwen).
    - `vram_manager.py`: Управление памятью и процессами.
    - `workers.py`: Фоновые задачи (YouTube DL и др.).
- `ui/`: Современный Fluent UI на базе `qfluentwidgets`.
