# AutoDubStudio v3 — UI/UX Design System
**Вдохновение:** [Files App](https://github.com/files-community/Files) (43.9k ⭐) — современный файловый менеджер Windows с Fluent Design

---

## 🎨 Дизайн-принципы

| Принцип | Реализация |
|---|---|
| **Mica/Acrylic фон** | `setMicaEffectEnabled(True)` — полупрозрачный фон как у Files |
| **OKLCH-цвета** | 16 тем, каждая из одного hue-угла (как daisyUI) |
| **3-шаговый воркфлоу** | Source → Configure → Progress (step-by-step карточки) |
| **Drag & Drop прежде всего** | Большая drop-зона с hover-анимацией |
| **Умные дефолты** | Авто-определение GPU → оптимальные настройки |
| **Скрытая сложность** | Ручной редактор скрыт до активации, лог компактный |

## 📁 Структура нового UI

```
ui/
├── __init__.py
├── theme.py           # OKLCH color engine (16 тем)
├── components.py      # DragDropZone, CollapsibleSection, StatusBadge, StepIndicator
├── main_window.py     # Главное окно с Mica + sidebar (как Files)
└── pages/
    ├── home.py        # Студия дубляжа (основная страница)
    ├── live.py        # Live-субтитры
    ├── tools.py       # Инструменты (Demucs)
    ├── settings.py    # API ключи + тема
    └── about.py       # О программе
```

## 🚀 Запуск

```bash

python run_v3.py

# Старый UI (v2) — всё ещё работает

```

## 🆚 Сравнение: v2 vs v3

| Аспект | v2 (app.py) | v3 (run_v3.py) |
|---|---|---|
| **Структура** | Одна длинная scroll-страница | 3 карточки-шага (Source → Config → Progress) |
| **Drag & Drop** | Невидимый, только на home | Большая анимированная drop-зона |
| **GPU-статус** | Всплывашка на 1 сек | Постоянный бейдж с названием GPU |
| **Ручной редактор** | Всегда виден (пустая таблица) | Скрыт, показывается только при активации |
| **Цвета** | Статические HEX | OKLCH-генерируемые (16 тем из 1 hue) |
| **Иконки** | Базовые FluentIcon | FluentIcon + кастомные бейджи шагов |
| **Лог** | 140px фиксированный | 120px, не мешает основному интерфейсу |
| **Навигация** | 5 вкладок | 5 вкладок (та же структура) |
| **Обратная совместимость** | — | Полная: engine.py поддерживает оба формата |

## 🎯 Ключевые улучшения

### 1. Drag & Drop Zone
- Большая область с dashed-бордером
- Анимация при наведении (border solid + цвет)
- Иконка меняется с VIDEO на ADD
- Текст меняется на "Release to load video"
- Работает глобально (на всём окне)

### 2. Step-by-step карточки
- **Шаг 1:** Выбор источника (drop-zone + YouTube URL)
- **Шаг 2:** Конфигурация (языки, модель, TTS, переводчик) + большая кнопка Старт
- **Шаг 3:** Прогресс (progress bar + лог + скрытый редактор)

### 3. Status Badge
- GPU Ready (зелёный) / CPU Mode (жёлтый)
- Горит всегда, показывает состояние системы

### 4. OKLCH Theme System
- 16 пред-сгенерированных цветовых схем
- Каждая тема = 1 hue угол (как в daisyUI)
- Генерирует accent, surfaces, text, semantic-цвета
- Автоматический QSS (таблицы стилей Qt)

### 5. Collapsible Sections
- Секции можно сворачивать (экономия места)
- Анимация через QPropertyAnimation

## 🔧 Технические решения

- **engine.py** теперь принимает и dict-конфиг (v3), и позиционные аргументы (v2)
- **manual_edit_signal** — новый сигнал для v3 UI формата редактора
- **resume()** — новый метод для совместимости с v3 форматом
- Все старые сигналы и методы сохранены
