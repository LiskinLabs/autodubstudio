# AutoDubStudio - Project Journal & Memory

## 🎯 Текущий Статус (GUI & Backend Интеграция)
- **Архитектура:** Полный переход на модульную V3. Основная логика в `engine.py`, компоненты в `backend/` (translator, vram_manager, workers).
- **Фронтенд:** Tauri + React (папка `gui/`). Внедрены темы (DaisyUI), мультиязычность (с автоопределением языка ОС), и система перехвата крашей.
- **Дистрибуция:** Сборка в виде `.exe` (NSIS) через Tauri для локального тестирования на ПК пользователя.

## 🛠 Инструкция для ИИ: Как собирать и обновлять `.exe` (CRITICAL)
Если пользователь просит "собрать .exe", "сгенерировать файл" или "обновить приложение на рабочем столе", ОБЯЗАТЕЛЬНО выполни следующие шаги:
1. Перейди в папку фронтенда: `cd C:\Users\silvestr.liskin\Desktop\AutoDubStudio\gui`
2. Запусти сборку Tauri: `npm run tauri build` (это запустит vite build и скомпилирует Rust бэкенд).
   *(Примечание: Если `tsc` жалуется на неиспользуемые переменные, временно убери `tsc` из скрипта build в package.json, чтобы сборка не падала).*
3. Дождись завершения фонового процесса (создается msi и nsis).
4. Скопируй готовый установщик на рабочий стол пользователя для тестирования:
   `Copy-Item -Path "C:\Users\silvestr.liskin\Desktop\AutoDubStudio\gui\src-tauri\target\release\bundle\nsis\AutoDub Studio_0.0.1_x64-setup.exe" -Destination "C:\Users\silvestr.liskin\Desktop\AutoDub Studio_0.0.1_x64-setup.exe" -Force`
5. Сообщи пользователю, что новый файл на рабочем столе готов к установке.

## ✅ Выполненные задачи (Бэкенд)
1. Замена `openai-whisper` на `faster-whisper`, устранение OOM (перенос микширования на потоковый FFmpeg).
2. Внедрен Time-Stretch (ffmpeg atempo) для подгонки голоса под тайминги субтитров.
3. Проброс stdout/stderr из subprocess напрямую в GUI через `log_signal` (исправлено зависание/freezing интерфейса при скачивании моделей PyTorch).
4. Синхронизация Ручного Режима (Manual Mode): `engine.py` корректно ждет снятия `pause_event.set()` от фронтенда (`/resume`).

## ✅ Выполненные задачи (Фронтенд - GUI)
1. Успешно интегрирован **DaisyUI** для поддержки смены цветовых тем (`data-theme`).
2. Исправлен краш кодировки (мультиязычность `store.ts`), добавлены строгие типы TypeScript для `translations` и авто-детект языка ОС.
3. Кнопка "Открыть результат" починена (корректно извлекается путь из лога `"Успешно: <путь>"` и вызывается `tauri/api/shell/open`).
4. Статус локальных ИИ (Ollama): Исправлено залипание в статусе "Отключено" (используем `127.0.0.1` вместо `localhost` в `useOllama.ts` во избежание проблем с IPv6/CORS в Tauri).
5. При продолжении ручного режима (`handleContinueFromReview`) ручные правки субтитров (`translatedSrt`) корректно синхронизируются обратно в рабочий массив сегментов.
6. Внедрена автоматическая отправка логов ошибок (Error Reporter) в GitHub Issues через FastAPI эндпоинт (используется GitHub PAT пользователя).
